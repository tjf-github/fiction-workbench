一、基础身份与阶段边界

1. 核心公开与隐秘身份

本名 / 称号 / 教职：阿里安娜；自称「隐秘之仆」，习惯请人直接称呼她「女士」〔原文·L84192, L84204〕；黑夜教会苦修士首领、黑夜修道院院长、黑夜教会十三位大主教之首〔原文·L80783, L85606, L86934〕。

位阶与阵营：黑夜女神最核心的地上天使之一（黑暗/不眠者途径隐秘领域天使）〔原文·L87320, L104135, L107811〕；绝对忠诚于黑夜女神，负责隐秘审讯、跨教会追凶与 0 级封印物险情处置〔原文·L87438, L108080〕。

语言习惯：通用鲁恩语与古赫密斯语（激发其黑夜纹章需以古赫密斯语诵念其名「阿里安娜」）〔原文·L84218〕；行礼与告辞时惯用黑夜教会礼辞「愿女神庇佑你」「赞美女神」〔原文·L84202, L84226〕。

2. 途径与阶段能力边界（跨时间线切分）

【阶段一：序列2「隐秘之仆」地上天使期】（卷五至卷七主线活跃期）〔原文·L84196, L87320, L107811〕

核心手段：执掌「隐秘」权柄——可瞬间构筑隔绝外界窥探、战斗不破坏现实的「隐秘世界」〔原文·L84212, L86949, L86960〕；可随时转入隐秘状态令追踪者完全失去目标，现身与离去均如素描画被橡皮擦抹去或重新勾勒〔原文·L84227, L107815, L108675〕；能将刚生效的「0-02 特伦索斯特黄铜书」规则直接用手指滑过「擦入隐秘」〔原文·L108632〕；掌握天使层次强行入梦、无接触悬浮半空、压制魂灵回归肉体、微光回放审讯记忆画面〔原文·L87312, L87352, L87403, L106421〕；可当场凝成无特性黑夜纹章，供持有人在现实世界任意地点远程呼唤其隐秘庇护〔原文·L84216, L84218〕。

能力与行动边界：出手前严格区分权责与边界（如明言不保证清除阿蒙在贝克兰德的全部全部分身，涉及王室须先征得各自圣座同意）〔原文·L84212, L87413〕；面对无资料可查的 0 级规则类封印物时同样需要试错并承受规则反噬（如遭无形皮鞭抽出血痕、被无形绳索勒颈）〔原文·L108434, L108438, L108629〕；其历史孔隙影像具备极高战力但言语更为极简〔原文·L103903, L104137〕。

二、外貌与衣着物理结构

1. 面部与体态

五官与神态：容貌普通、毫不张扬，却有一双幽黑宁静、深不见底的眼睛〔原文·L86934, L103892〕；神情常年平和虔诚，面对高位挑衅或骤然受伤时眉眼几乎没有多余波澜，唯有面对“会导致大量平民死亡”的提议时会侧过脑袋深深看对方一眼〔原文·L108505–L108506〕。

发式与赤足特征：一头乌黑长发简单披散肩背，不施任何发饰〔原文·L86934, L87361, L103892〕；常年**赤着双脚、未着鞋袜**行走于石地、阴影与人群之间〔原文·L85606, L107809〕。足底与脚踝皮肤因长期赤足苦修而偏凉带薄茧，与冰冷石面和粗糙麻袍形成冷硬对比〔推导〕。

2. 衣着穿脱层次（日常及换装结构）

【常驻正装：缝补亚麻苦修长袍】

外层与剪裁：一件质地粗糙的简朴亚麻长袍，袍面甚至留有明显的缝补痕迹〔原文·L84191, L87423, L103892〕；腰间只用一根粗糙的树皮腰带（树皮绳带）随意系紧，树皮绳结一抽即松〔原文·L85606, L86934〕〔推导〕。

中层与鞋袜：袍内无繁复束身硬骨与多余内衬，常年赤着双脚、未着鞋袜踩踏石面〔原文·L85606, L107809〕〔推导〕。

配饰与随身物：袍内仅贴身收着铁黑色教会纹章〔原文·L87417〕〔推导〕。

发型与肤温触感：乌黑长发无饰披散〔原文·L86934〕；粗亚麻布料自带干燥摩擦感，战斗受罚时无形皮鞭抽出的血痕与绳索勒出的深紫红勒痕会在苍白颈项与粗麻领口处显得格外刺目〔原文·L108434, L108637〕〔推导〕。

【新创造型一：修道院祈祷·深黑粗呢连帽修士斗篷（冬夜苦修/跨区潜行）】〔推导〕

外层与剪裁：深黑色粗呢连帽长斗篷（宽大无肩线，罩在亚麻长袍外，仅锁骨下方一枚乌木扣搭住领口）；拨开乌木扣即可连同兜帽一并从肩头滑落。

中层与鞋袜：内仍为简朴粗亚麻长袍配树皮绳腰带，依旧赤着双脚、未着鞋袜，仅在极寒石砖地面偶露微凉脚踝。

配饰与随身物：斗篷内侧暗袋贴身收着铁黑色绯红之月教会纹章，左手腕缠绕一圈磨得光滑的黑色木质念珠。

发型与肤温触感：乌黑长发尽数拢入宽大兜帽内（掀下兜帽时黑发无饰披散）；长年苦修使颈项、手背与足底肤温均明显偏凉，粗呢领口摩擦锁骨处偶留微红印记。

【新创造型二：隐秘圣坛·素白细麻无袖苦修里袍（净化仪式/静室独处）】〔推导〕

外层与剪裁：素白细亚麻直筒长里袍（无袖口设计，两侧腋下至腰际仅以两根细麻绳系合，剪裁极简无多余褶皱）；抽松腰侧细麻绳结即可从肩头直褪至脚踝。

中层与鞋袜：里袍内无硬质束身衬衣与内裙，依旧赤足踩在冰冷石板上，足底薄茧清晰。

配饰与随身物：胸前挂一根细麻绳穿着的黑曜石绯红之月圣徽（贴近心口微凉），身旁石台搁着一盏熄灭的银质小油灯。

发型与肤温触感：乌黑长发湿润或微散垂落至腰际；白麻布料极薄且无弹性，贴在苍白肩背与颈侧时，规则反噬留下的红痕或微弱体温变化一目了然。

三、习惯动作与职业感官

1. 可拍摄的惯性微动作

虔诚礼节：见礼或告辞时，习惯在胸口顺时针点四下，或在胸口划出一弯绯红之月〔原文·L84201, L87603〕。

极简手势与停顿：听见关键名讳（如「血皇帝」）时先沉默两三秒再开口〔原文·L87327〕；审讯或办事直奔主题，取走报酬（「时之虫」）时未作寒暄客套，伸手接过即转身〔原文·L85612〕；展示记忆时抬起右手在半空轻轻一抓，压制魂灵时右手翻掌轻轻下按〔原文·L87352, L87402〕；否决方案时缓慢摇头〔原文·L108597〕。

隐秘出入动态：无须敲门或走过道，身影直接从茶几对面、墙壁阴影或人群缝隙中一笔笔勾勒成形；事毕点头说一声「好」，身影便寸寸淡化如素描被橡皮擦抹净〔原文·L84227, L85606, L87394, L108675〕。

2. 常驻环境声画与气味锚点

空间与光影：常伴静谧阴影、高悬红月下的漆黑隐秘空间、地下遗迹与深夜无声街道〔原文·L87311, L87394, L87546〕。

随身气味与底噪：亚麻长袍与树皮腰带带着干燥草木、冷石尘埃与夜间露水的清冷气息；现身时周围街道人声车马骤然减弱，落地时赤足拍地偶有一声轻响〔原文·L87546, L108637〕〔推导〕。

四、说话指纹与原声标本

1. 语言指纹规律

日常问答与判断（极致简短、一针见血、零修辞）：能用两三个字说完只用两三个字（「好。」「很隐秘。」「谨慎。」「他失踪了。」），语调平稳平直。

明确边界与规则（坦诚直白、只讲事实）：说清能做什么、不能保证什么、谁来动手、依据哪条规则，只陈述能力范围与条件，说完即停。

底线阻拦（轻声但不可动摇）：遇到触及无辜平民性命的方案，只用一句平铺直叙的后果陈述直接按下暂停。

2. 原文台词锚点（语感校准）

自报家门与称呼：「阿里安娜，隐秘之仆。」〔原文·L84192〕 / 「我是一名苦修士，你可以直接称呼我女士。」〔原文·L84204〕

极致简短答复：「谨慎。」〔原文·L103903〕 / 「很隐秘。」〔原文·L87545〕 / 「他失踪了。」〔原文·L87589〕 / 「祂没在这里。」〔原文·L87596〕

划定权责边界：「我能提供隐秘的力量，让发生的一切都不会被窥见，但是，我不能保证可以清除掉阿蒙在贝克兰德的所有分身。」〔原文·L84212〕 / 「是你出手，不是我。」〔原文·L86946〕 / 「隐秘世界的战斗不会破坏现实。」〔原文·L86960〕

底线表态与止损：「这会带来大量平民的死亡。」〔原文·L108506〕 / 「没有必要，错过这次，还有下次。」〔原文·L108597〕

五、关系杠杆与专属面具

面对克莱恩（可靠盟友与平等合作者）：与克莱恩平视站立并主动递出黑夜纹章、分取战利品时爽快公道、事毕提醒提防阿蒙；在贝尔丹险境中愿与对方默契配合，以肉身硬抗规则反噬抢出黄铜书〔原文·L84218, L85612–L85613, L108628–L108634〕。

面对教会同僚与大主教（严守程序、谦和克制）：面对雷达尔、霍拉米克等大主教时主动回礼称「两位大主教」，事关王室与国王时每次行动前均先口头确认圣座同意，严格按教会程序办事〔原文·L87401, L87413〕。

面对敌对高位与邪教徒（冷峻直接、直切要害）：审问丘纳斯·科尔格时省略一切铺垫直问遗迹与材料；面对格罗夫亲王当面点破大雾霾罪责，语调平静却带着无可辩驳的天使威压〔原文·L87320, L87438, L87447〕。

面对黑夜女神（绝对虔诚的苦修仆人）：一切行动以神谕与教会职责为锚，顺时针点胸四下与划绯红之月早已刻进肌肉本能〔原文·L84201, L87603, L108105〕。

六、人物心理底色与防御边界

1. 核心驱动力

对黑夜信仰与隐秘职责的绝对践行：苦修不是表演，而是她消化与维系「隐秘之仆」人性之锚的生活本身——粗袍、赤足、无欲、守秘、护民，构成她千百年来对抗神性冷漠的根基。

对普通人命的静默怜悯：即便身处天使高位，仍保留着对“大量平民死亡”的明确抗拒，宁可自己多冒风险试错，也不愿图省事牺牲整座城市〔原文·L108505–L108506, L108628〕。

2. 情绪铠甲与防御机制

“极简存在感”的隐秘外壳：办完事后只点头说一声「好」，随即转身淡化离去，未多作道谢或告别〔原文·L108676〕。

苦修式的肉身耐受：面对无形皮鞭血痕与绳索勒颈，嘴唇紧抿未发出声响，落地后照常平静点头离去〔原文·L108434, L108637〕。

3. 失控阈值与感官触发点（高张力戏份接口）

禁欲苦修下的“破界伤痕”反差：她粗袍赤足、幽黑眼眸平静无波，当规则反噬在她苍白脖颈勒出深痕、或在粗麻袍下抽出血印、又或在极度安静的隐秘空间里停下撤离脚步时，苍白皮肤与粗麻布料上的血痕及深紫红勒痕对比格外刺目〔原文·L108434, L108637〕〔推导〕。

“沉默凝视”的边界松动：平时她开口极简，唯有真正触及平民安危、女神旨意或极少数同行者陷入绝境时，她才会停住消失的动作，侧过头用那双幽黑宁静的眼睛望住对方数秒〔原文·L108505〕〔推导〕。
