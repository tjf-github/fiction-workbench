## 当前边界

此仓库是资料、设计与实验工作区，尚不是可直接运行的完整写作系统。11 月 14 日交付不含原本、证据包正文或 Fiction skill 工作树；不证明 OpenFic 已接通。世界书整本保留查阅、人物书独立，按需派生挂载，单份／单次不超过 4 万 Unicode 字符。

验收建议 `verified` 不等于用户确认；`needs_rework`、未验收修订、矛盾与 C4 待裁定项保持原状态。11 月 14 日生产停线未因本次归档而恢复：后续生产、验收及权威切换仍按交接要求处理。

原交付的历史名称、内部路径和文件正文保持不变，便于引用与校验；其中云端绝对路径是来源线索，不保证在本机可用。

## 保存方式

仓库使用私人可见性。引用原作和第三方 skill 的材料按其原有权利与许可处理；本仓库不统一授予开源许可。凭据、环境配置、临时文件与重复压缩包不入库；交付中作为证据保留的日志仍入库。
