# 小说创作工坊 · Fiction Workbench（v3 四库隔离架构）

为写作流水线提供干净、去 AI 套话的世界观硬常识、六段式人物书、极简物理底噪词表、三步协同写作 Skill 与上游装配转录过滤器。

---

## 一、四库隔离体系

仓库资料库已彻底清除旧版易诱发 AI 套话与书面腔的范文句库（W4 锚点包）、负向禁令集（W5）与冗余旧版草稿，收敛为以下四个独立目录：

| 目录 | 定位 | 挂载规则 |
|---|---|---|
| [`W1-世界观硬常识/`](W1-世界观硬常识/) | 静态规则层：22 条途径核心能力名录、魔药消化与失控代价、五海航线与货币换算、语言使用场景、势力通则 | 默认只读参考，严禁整段照抄成说明书腔 |
| [`W2-人物书定稿/`](W2-人物书定稿/) | 统一六段式人物档案（以 [`嘉德丽雅-人物书-定稿版.md`](W2-人物书定稿/嘉德丽雅-人物书-定稿版.md) 为唯一标准样板，涵盖嘉德丽雅、艾德雯娜、贝尔纳黛、特雷茜、伊莲、潘娜蒂亚、阿里安娜、卡特琳娜、雪伦夫人） | 上游装配时**严禁整份塞入**，每角色每场仅按需摘录 **3–5 条**物理锚点与原声标本 |
| [`W3-场景与物理词表/`](W3-场景与物理词表/) | 极简感官底噪库 + W3 场面规程通用模板 + 单场基准实例（[`W3-推门场-已校准样卡.md`](W3-场景与物理词表/W3-推门场-已校准样卡.md)）与按角色主场及场面类型归档的 [`W3-角色出场摩擦样卡/`](W3-场景与物理词表/W3-角色出场摩擦样卡/) | 仅按地点与材质抽取物理词组，按场面类型抽取对应样卡，零范文、零情绪比喻 |
| [`X1-成年向隔离词表/`](X1-成年向隔离词表/) | 高张力与成年向物理/感官词表（含 [`_隔离规则.md`](X1-成年向隔离词表/_隔离规则.md)） | **常规非 18+ 流水线默认关闭且严禁加载**；仅手动切换成年向模式时，配合 W2 第 2 节与第 6 节按需挂载 |

- **流水线路由配置**：[`pipeline/v3_pipeline_config.json`](pipeline/v3_pipeline_config.json)

| 环节 | 绑定执行环境 | 核心职责与约束 |
|---|---|---|
| **上游装配** | **OpenFic / DSH** | 仅读取 W1/W2/W3 生成标准《W3 场面卡》，执行防红烧肉转录过滤，不执笔正文 |
| **初稿生成 & 局部返修** | **OpenFic（轻对话客户端配置）** | 无重型工具脚手架，执行 Skill 阶段一与阶段三，保真人口语与人味毛边 |
| **句级纯审计** | **Grok（`grok-4.7`）** | 执行 Skill 阶段二，只列 **3–6 条**带原句定位的硬伤，**严禁输出改写全文** |

## 三、本地校验与过滤工具

### 1. W3 场面卡上游装配转录过滤器（防红烧肉效应）

检查场面卡是否违规挂载 `X1`、整份塞入 `W2`、锚点超限（>5 条/人），或残留负向禁令与抽象态势总结句：

```powershell
# 常规非 18+ 模式检查
python -X utf8 -B scripts/w3_assembly_filter.py check W3-场景与物理词表/W3-推门场-已校准样卡.md

# 自动转译常见负向触发词与抽象总结句
python -X utf8 -B scripts/w3_assembly_filter.py sanitize <待清洗场面卡.md>

# 仅手动切换成年向模式时显式放行 X1 检查
python -X utf8 -B scripts/w3_assembly_filter.py check <成年向场面卡.md> --adult-mode
```

### 2. 资料入库前原文出处核对

运行 `python -B scripts/review_material_ui.py` 打开本地并排核对界面，或使用命令行工具 `scripts/review_material.py` 执行 `locate` / `check`。

### 3. 运行单元测试

```powershell
pytest tests/
```
