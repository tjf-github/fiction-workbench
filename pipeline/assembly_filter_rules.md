# OpenFic / DSH 上游装配转录过滤器规范（防红烧肉效应）

> 配置文件：[v3_pipeline_config.json](v3_pipeline_config.json) · 执行脚本：[w3_assembly_filter.py](../scripts/w3_assembly_filter.py)

## 一、四条硬性守门规则

1. **X1 默认隔离门禁**
   - 常规非 18+ 流水线（`adult_mode = false`）严禁挂载或引用 `X1-成年向隔离词表/`。
   - 仅当手动传入 `--adult-mode` 时，允许配合 W2 第 2 节（外貌与衣着物理结构）与第 6 节（人物心理底色与防御边界）按需挂载。

2. **严禁整份塞入 W2 全文（每角限摘 3–5 条）**
   - DSH / OpenFic 装配 W3 场面卡时，禁止将整份 W2 人物书粘贴进提示词。
   - 每个出场角色仅按需摘录 **3 到 5 条**本场实际用到的物理特征、随身物件与原声标本。

3. **拦截负向禁令与否定概括词（防红烧肉效应）**
   - 凡出现“未做第二次试探 / 不做第二次试探 / 未表现出明显异常 / 不顶撞也不讨好 / 禁止问…… / 不要写……”等负向触发词，极易诱发下游写手模型反向写出字面照抄句。
   - 一律拦截并转译为正面的物理行为特征或客观边界（例如：`不做第二次试探` → `先看书面资料再点头`；`不顶撞也不讨好` → `沉默两秒后把话头转回正事`；`禁止写……` → `留白边界：……留给后文展开`）。

4. **拦截抽象态势总结句**
   - 凡出现“两人刚把一段话收在半截”“保留是否赴约的决定权”“没表态去不去”等上帝视角总结句，一律拦截并改写为视角人物直接看见、听见的物理动作与客观结果（如 `靠回椅背默认留下来等这一晚`）。

## 二、命令行用法

```powershell
# 常规非 18+ 模式检查 W3 场面卡（退出码 0 通过，1 命中违规）
python -X utf8 -B scripts/w3_assembly_filter.py check W3-场景与物理词表/W3-推门场-已校准样卡.md

# 自动转译常见负向触发词与抽象总结句并输出清洗后文本
python -X utf8 -B scripts/w3_assembly_filter.py sanitize <待清洗场面卡.md>

# 仅在手动切换成年向模式时显式放行 X1 挂载检查
python -X utf8 -B scripts/w3_assembly_filter.py check <成年向场面卡.md> --adult-mode
```
