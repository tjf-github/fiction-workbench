# 04 · 语言使用场景（硬常识速查）

> 定位：静态规则层（W1），规定不同语种在日常社交、海上交涉、隐秘聚会与仪式魔法中的切换规则，避免语种穿帮。

| 语种 | 适用场景与说话人特征 | 常见触发与切换规则 |
|---|---|---|
| **鲁恩语** | 鲁恩王国官方与通用语；贝克兰德、廷根、拜亚姆等殖民港口最通用的日常及商业语言 | 海上跨国交易、港口查验、鲁恩籍或长期在苏尼亚海活动者默认用语 |
| **因蒂斯语** | 因蒂斯共和国官方语；上流社交、时尚与艺术圈常用；贝尔纳黛、嘉德丽雅、伊莲均熟练使用〔原文·L28349, L49792, L50079〕 | 嘉德丽雅日常惯用因蒂斯语与鲁恩语；因蒂斯出身者紧张或自语时易切回母语 |
| **古弗萨克语** | 北大陆诸语共同源头之一；古典、庄重，具备一定神秘学承载力 | **塔罗会固定通用语**（如嘉德丽雅入灰雾必切古弗萨克语〔原文·L50079〕）；贵族古典文献与古老誓言 |
| **赫密斯语 / 古赫密斯语** | 神秘学通用语；**古赫密斯语**能直接撬动自然与灵性力量〔原文·L409, L530〕 | 祈祷诵念尊名、举行仪式魔法、激活纹章（如用古赫密斯语念出「阿里安娜」激发黑夜纹章〔原文·L84218〕）、制作符咒 |
| **巨人语 / 精灵语 / 龙语** | 古代超凡种族语种，自带强灵性效应，常用于特定途径的高阶咒文与古老遗迹铭文〔原文·L409, L530〕 | 仅限对应途径、学者或读懂古代文献者使用（如艾德雯娜考据巨人王庭与精灵遗物） |
| **罗塞尔自创文字（中文简体）** | 罗塞尔大帝日记专用密码，本世界除穿越者外无人能直接识读 | 贝尔纳黛与嘉德丽雅长期高价求购其解读方式〔原文·L58144〕 |
