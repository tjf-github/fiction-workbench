# 《旧栈桥的便条》原版 skill 试跑

嘉德丽雅推开未来号的船长室。贝尔纳黛和格尔曼已经看过一张来路不明的约见便条。嘉德丽雅认出纸背的转驳补给记号，于是把格尔曼留下，先叫水手来问。人设参照 W2 人物书，开场沿用《归来》候选总谱。便条、旧栈桥和查问水手是本次试写情节。

[上游材料与来源](上游材料.md) · [DSH 初稿](初稿.md) · [Grok 审计](审计.md) · [DSH 返修正文](返修正文.md)

## 人物、信息差和句子

| 检查点 | 观察 |
|---|---|
| 嘉德丽雅像不像在管自己的船 | 初稿把她的决定落在一个可见证据上。她认得转驳补给记号，能叫人来问。两版都保留她把便条压在六分仪底座下，以及格尔曼答应等一会儿。人物的职责比上一轮小镇试题更能约束行动。 |
| 贝尔纳黛和嘉德丽雅有没有写出旧关系 | 初稿借望窗、格尔曼先看一眼贝尔纳黛和嘉德丽雅的不悦来暗示先前谈过。返修删去了嘉德丽雅无从知道的那段心理。视角准确了，但贝尔纳黛与嘉德丽雅的旧关系余味也更薄。两版都没有把两人明确写成已经决裂。 |
| Grok 抓对了什么 | 审计 L15 正确指出嘉德丽雅没听见进门前的问答，初稿却知道贝尔纳黛先单独问过格尔曼。DSH 删掉这段越界推断。它还去掉了「等多久不由你说」「去不去也不由我说」的对称宣言，保留了决定落实到纸条和当值水手上的动作。 |
| 审计删掉了哪些有效信息 | 关于泊位记号的证据上限，初稿明确只够查经手船只。返修仍在问哪条船捎来，未直接指认送信人，但读者少了一层知道她为什么只能问到这里的依据。 |
| 改稿有没有新伤 | 原本的叙述「他顿了一下」改成对白内的「他在那儿停了一下」，像格尔曼在说一个没有指代的人，中断了对话逻辑。「我看过正面／背面呢／没留意」也依然是三句问答。返修正文从 826 字符缩为 674 字符（不计空白），低于题设的 800 字下限。 |

初稿 23 段，返修正文 22 段，其中 14 段完整保留。凉茶和厨房油烟还在，船长室的走位和收尾也还在。原版 skill 在这个样本里的实际收益主要是让 Grok 抓到视角越界、让 DSH 做局部删除。人物口气和有用的证据说明仍需要逐句判断。

## 运行与文件处理

- DSH 初稿和完成的返修均用桌面安装包的 headless 入口和 `deepseek-flash`，两次都核对了原生 `skill` 工具返回的完整原文。Grok 通过 Claude Code `Read` 成功读取同一字节副本，CC Switch 两条会话请求均记录 `grok-4.7` 与 HTTP 200。
- DSH 初稿 14.20 秒，Grok 审计 103.71 秒。前两次 DSH 返修在推理开启时分别触及 8192 与 16384 token 上限，没有完整正文。第三次只对本次调用关闭推理，12.40 秒完成。初稿、审计和返修使用同一版 skill，规则未手工转写。
- 模型返修原始回复附逐条核对和 L 行号，越出了只交正文的要求。`返修正文.md` 仅提取正文、去掉定位编号，句子照存。中间请求、提示与运行元数据已在定稿整理时清理。
- 本轮把 Grok 的六条原样交给 DSH 自行筛查，与原版 skill 所述的人工筛审步骤有差别。一次场面没有同题无 skill 对照，结果只反映这批上游和这个样本。
