# 暴雨前交班 · 单场试跑

原创场面。许梅要赶末班接驳车，老秦知道罗师傅还留在河边。这里只看从初稿到局部返修的变化。

| 环节 | 实际运行 | 用时 | 产物 |
|---|---|---:|---|
| 初稿 | DSH 桌面安装包的 headless 入口，请求 DeepSeek 官方 API 的 `deepseek-flash`，low | 11.13 秒 | [初稿](02-DSH初稿-v2.md) |
| 审计 | Claude Code 经 CC Switch，网关按会话匹配到 `grok-4.7`，HTTP 200。客户端请求 `claude-opus-5`，传入 low 参数 | 128.05 秒 | [Grok 审计](04-Grok审计.md) |
| 返修 | 同一 DSH 入口与模型，low | 7.72 秒 | [返修稿](06-DSH返修.md) |

DSH 首次启动时，本地权限阻止了旧 profile 写入。改用隔离目录后，另一次启动又因工具执行器被禁用而在生成前退出。这两次均未返回初稿。恢复执行器后，初稿和返修各完成一条正文请求，两个会话记录都显示 0 次工具调用。Grok 完成一条审计请求。三段均保留原始文本。

## 前后差在哪

| 观察 | 局部变化 | 读感 |
|---|---|---|
| 老秦的顾虑 | 删除许梅的「你怕我叫人？」和旁白的「没直说」，留下「镇上那帮人一来，车灯一开，话就不好说了」 | 这一处减得最好。读者从老秦自己怕的场面听出顾虑，两个角色少做了一轮问答 |
| 许梅开始行动 | 删掉「那你的意思是？」和随后的「没答」，直接接许梅拿手电走 | 少了一组专门给动作让路的问答。搪瓷缸、湿裤脚和结尾踩水还在 |
| 应声的方位 | 初稿「河那边应了我一声」改成「就这下层这侧应了我一声，是他本人」 | 地理误读消了，口气变硬。可手改为「我在下头喊了一声，老罗应我的。」这句是人工建议，原始返修稿照存 |
| 段落与收尾 | 结尾句保留，全文的段间空行被去掉 | 18 处段间空行消失，模型返修稿仍需恢复原来的段落间距 |

Grok 六条全部给了原句定位及操作，未重写全文。删解释、删搭桥问句比要求模型重新说清一条信息更稳。第六条认为反复摸钥匙像在埋线，删除后确实更干净，其原本也可以读作紧张时的习惯动作。返修额外补了「最后一班」并校正交接本的位置，属于人工筛定时加入的事实和连续性修正。

在这个样本上，审计找到了原稿的地理歧义和几处可以定点删除的冗余。返修保住情节、视角和收尾，仍留下一句生硬对白以及段落间距变动。单场没有无 skill 的对照组，也没有计量人工修改耗时，结论限于这次前后稿。
