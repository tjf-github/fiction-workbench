# 01 · 地点物理底噪词表（极简感官底噪库）

> 定位：仅提供按地点分类的纯物理声、光、味、温触底噪词组，供 W3 场面卡按配额（常规场 1–2 处）抽取落地。**严禁写入完整描写范文、情绪比喻或象征闭环句。**

## 一、船舱与甲板（未来号 / 黄金梦想号 / 黑死号 / 客轮）
- **声音**：木质船体受潮轻倾吱呀声、船舷拍浪闷响、远处甲板皮靴脚步声、缆绳拉紧摩擦木桩声、起吊滑轮铁链碰撞声、舱门铜合页轻响、壁钟报时滴答声、风灌过舷窗缝隙哨音
- **气味**：海风腥咸潮气、松油与湿木头味、黄铜仪器微腥铜油味、旧羊皮纸与干墨水味、冷茶涩气、灯油微焦味、咸水晒干后的麻绳味
- **光影与触感**：黄铜六分仪冷光、油灯昏黄晃动光斑、舷窗外铅灰海面反光、红木桌面微凉潮意、厚地毯踩陷无声、甲板湿滑盐霜、晾晒粗渔网硬糙感

## 二、港口与码头（拜亚姆 / 普利兹港 / 恩马特港 / 旧栈桥）
- **声音**：潮水拍击木桩哗啦声、汽笛低沉闷鸣、装卸木箱砸地钝响、马车铁轮碾过湿石板轱辘声、酒馆门推开漏出的嘈杂人声、海鸥贴水面短鸣
- **气味**：腐烂海藻与鱼腥味、焦煤烟尘味、湿麻袋与香料烟草混杂味、劣质朗姆酒气、潮湿石阶青苔味
- **光影与触感**：雾气里发晕的煤气灯黄光、石板路积水冷反光、木栈桥受潮松动微晃、海风裹细雨打脸发凉、铁链锈斑刮手

## 三、贝克兰德 / 廷根街区与宅邸（客厅 / 卧房 / 书房 / 马车）
- **声音**：煤气壁灯嘶嘶微响、壁炉煤炭轻爆声、高跟鞋踩木地板轻脆步声、银勺碰瓷杯沿细响、雨点打在玻璃窗上哒哒声、楼下街面马蹄与车铃远声、门锁铜舌咔哒落位声
- **气味**：炭火灰与煤烟味、红葡萄酒醇气、冷脂粉与干花香、旧书籍霉纸味、雨后湿泥与马粪街气、漆木家具与蜡油味
- **光影与触感**：煤气灯冷白/淡黄光晕、落地窗雨痕折射街灯、铁灰色保险柜冷硬漆面、全身镜冰凉镜面、羊毛地毯阻滞感、丝绒窗帘厚重垂感

## 四、教堂、遗迹与灰雾空间（圣堂 / 地下石室 / 迷雾小镇）
- **声音**：空旷石廊脚步回音、蜡烛火苗轻跳声、石门摩擦地面沉闷刮擦声、死寂中衣物摩擦细响、远处不明来路的低沉风声
- **气味**：冷石尘埃味、陈年烛蜡与干草药味、潮湿泥土霉味、夜间露水冷气、若有似无的铁锈血腥味
- **光影与触感**：彩绘玻璃漏下的暗淡微光、石砖刺骨凉意（赤足触感）、青铜长桌冷硬质感、灰白浓雾湿冷贴面、阴影边缘骤然发暗
