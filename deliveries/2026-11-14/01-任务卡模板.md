# 任务卡模板（复制后填变量）

> 每张卡必须自包含；工位是新会话，没有上一轮记忆。

# 任务卡 <WP-ID> · <标题>

## 你的角色
你是<生产/合并/验收>工位，只做这一张卡。不读卡外文件，不改任务板，不验收自己。

## 唯一输入（白名单）
- <路径1>（只读第 X–Y 行 / 全文；sha256 <...>）
- <路径2>

## 禁止读
- `90_旧库-只读/`、`资料库-18+/` 正文、旧人物卡/旧细场方案、`D:\vsproject\Fiction\`

## 动笔前（必须先回，否则不许产出）
只回三行：
1. 实际读到的文件与行段；
2. 本任务三条硬约束（从资料里抄，不许自创）；
3. 有没有缺文件。
没读到就写"没读到"，不许用记忆补。

## 产出
- 路径：<...>
- 格式：<表头 / 字段 / 行数上限>
- 结尾附状态 JSON：见计划书附录 B

## 自检
- [ ] 每条事实有出处（原本·部·章·行号 / 节号 / URL）
- [ ] 无 18+
- [ ] A 类无成句、无形容词性格
- [ ] 无编造；缺写〔缺〕
- [ ] 条数/行数达标

## 回报（≤20 行）
- 产出路径 + 行数/条数
- 自检结果
- 3 条最不确定的地方
- 一句话：这份材料够不够支撑一个场景？为什么

## 停手条件
缺文件 / 行号对不上 / 输入超 4 万字符 / 出现黑名单内容 / 无法判断——停手回报，不许猜。
