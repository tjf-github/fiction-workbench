## 0. 一页摘要

**目标**：产出 4 类交付物 + 1 个可选实验：
1. 世界书（整本，A 类条目表 + 出处）；
2. 人物书（12 个交付文件 / 13 个名字；特雷茜＋红发伊莲合一份）；

5. 规则短卡（硬规则 v2 / 禁令候选 / 【待补】条款）。
**可选实验**：W9 单场景试写，只产出实验记录，不进 `50_产出`、不算交付物、需你单独批准。

**范围**：只产材料；不写正文入库、不建 Openfic Character、不填【待补】、只做非 18+、不复用旧人物卡/旧细场/旧气味书。
**新创句**：只允许出现在人物书 B-语体栏（二创未写过的角色），标〔新创〕、过全部门禁；**世界书、规则、任务卡一律不允许新创句**。

**先试点，再铺开**：D1 只开 **2 个生产会话**（W1a 世界书前半 + W2 贝尔纳黛）+ 1 个验收，跑通"任务卡→报读段→产出→本地校验→验收"；测一次通过率和交接耗时后，再决定是否扩到 4–6。

**硬闸门**：
1. 每条事实有 **证据 ID**（可回原本行号/节号）；出处存在 ≠ 支持结论，语义支持另验；
2. A 类固定列（主体｜属性/关系｜值｜证据 ID），禁自由叙述；
3. B 类逐字可回冻结源；标注 `origin=first_book|guimi|new`；
4. C 类固定列（场次｜状态项｜入场值｜出场值｜依据），禁动作过程；
5. 18+ 关键词筛查 + **人工逐条审读**；不把"扫描 0 命中"写成"已证明为零"；
6. 8 字重合：**生成正文** vs 原本/归来 = 0；**B 原句**（origin≠new）豁免；**B 新创**（origin=new）必须 8 字=0；A 台账查 ≥20 字连续照抄 = 0；
7. 【待补】只写"不填条款"；【待补】小节现为 **5 个标题**（以冻结清单为准）。

**落盘原则**：**bot 回传、本地单点落盘**。本地是唯一写任务板/状态/权威目录的角色；grokbot 默认不直写库（直写需先通过能力预检 + 目录权限验证）。

## 3. 全局铁律

### 3.1 来源权威（四类，必须标）

| 类 | 来源 | 能证明什么 | 标记 |
|---|---|---|---|
| 原著事实 | 原本 | 第一部事实的唯一依据 | `first_book` + `confirmed` |
| 二创既定 | 归来（非18+） | 二创里已写的事实/语体 | `guimi` + `confirmed_guimi`（不冒充第一部） |
| 写作约束 | 现行 00_规则 / 裁定 | 怎么写、禁什么 | `rule` |
| 外源候选 | 网络/旧稿推测 | 只能进候选，不进正文 | `web_supplement` / `unverified` |

### 3.2 禁读与候选池

- 禁读：`90_旧库-只读/`、旧人物卡、旧细场、旧气味书、`资料库-18+/` 正文、`D:\vsproject\Fiction\`。
- W0 从旧库复制/摘录的 **不是"干净副本"，而是"隔离候选池"**：路径 `输入包/候选-*.md`，文件头写死"候选，未经核验"；每条事实必须回原本重核，未核的进附录/不挂载。
- 旧世界书稿只用于"知道要覆盖哪些节"，不能作为事实依据；旧总则只用于"知道禁令覆盖范围"；旧已锁备忘只用于"候选 13 条"，逐条重新确认。
- **自测样本**：用人工构造的最小坏样本（缺出处/成句/18+/30 字照抄），**不用旧上游卡/旧定稿**。
- **受限源通道（W0-5）**：`资料库-18+/` 正文只有**本地操作者**可接触；先做关键词筛查 + **逐条人工审读**，冻结 `输入包/非18+白名单.md`（含 sha256），之后 `prep_mentions.py` 只从白名单抽句；补入的上下文同样审读。无人工审读则停用归来来源，人物书 B-语体记〔缺〕。

### 3.3 文档三类（固定列）

- **A 台账**：`主体 | 属性/关系 | 值 | 证据 ID`。值只写名词短语/数字/专名；禁自由叙述、禁形容词性格。
- **B 锚点**：`原句 | 出处 | 可拍摄 | 人物相关性 | origin`。origin≠new 必须逐字可回冻结源；origin=new 只允许人物书 B-语体，标〔新创〕，**必须 8 字=0**，并单列允许角色/栏位（仅二创命中 0 的角色，每人 ≤3 条）。
- **C 节拍**：`场次 | 状态项 | 入场值 | 出场值 | 依据`。禁"内容一句"、禁动作过程。
- 不允许"半成品句子"：任何文档必须声明 A/B/C；默认 A。

### 3.4 其他铁律

1. 18+：本阶段只用非 18+；整条删除，不转述、不概括、不留占位；人工审读，不靠关键词自证。
2. 缺就写〔缺〕；推断只进 C 类问题清单。
3. 不写正文、不设计新情节；W9 例外且需批准。
4. 一会话一 WP；不串题、不中途改系统提示词。
5. 先报读段 + 本地投递 hash + 验收定位题；报不出/答不上=没读，停手。
6. 产出文件名/格式/数量按任务卡；不合格式退回。

## 4. 角色与调度

### 4.1 座位

| 席 | 数量 | 职责 | 禁止 |
|---|---|---|---|
| 调度席 | 1（人或 1 个 bot 会话） | 读任务板、派卡、收回报、更新状态、决定重跑 | 不生产、不改产出 |
| 生产工位 | **试点 2**，稳定后 4–6 | 按卡产出单一交付件 | 不读别 WP 输入、不验收自己、不直写权威目录 |
| 验收席 | 1（试点），后 2 | 按验收合同抽检、写报告 | 不修内容、不做生产 |
| 本地席 | 1（DSH/脚本） | 基线、候选池、证据包、校验、落盘、入库、Openfic 导入 | 不做需要判断的内容生产 |

**硬规则**：生产 ≠ 验收；验收席独立会话、独立任务说明、隐藏生产者自评；**不同模型家族是加分项，不是硬阻断**。

### 4.2 文件信箱（本地单点写）

- 本地是 **唯一** 写 `00-任务板.md`、`30-状态/*.json`、权威目录的角色。
- 每个交付件一个 ID（如 `W2-贝尔纳黛`），一个输出文件、一个状态记录；**不共用 W2.json**。
- 状态词固定：`ready → running → submitted → verified | needs_rework | blocked`；`submitted` 不等于通过。
- 状态记录含：尝试编号、输入版本/hash、输出 hash、验收报告路径、未决问题。
- grokbot 默认只回传内容；要直写，先通过 W0 的能力预检 + 目录权限验证。

### 4.3 生命周期（8 步）

1. 本地/调度选 `ready` 交付件；
2. 取任务卡 + 本地生成的输入包（含 hash）；
3. 新开会话，粘贴卡 + 输入；
4. 工位回报读段 + 三条硬约束；本地核对投递 hash；
5. 工位产出（回传或直写）；本地落盘并算 hash；
6. 本地 `verify.py` 跑结构/出处/18+/计数；写校验报告；
7. 验收席抽检（含 3 道定位题：证据 ID + 短引文 + 上下文关系）；写报告；
8. 状态置 `verified` 或 `needs_rework`；返工同卡附失败项。

### 4.4 上下文预算

- **总输入 ≤4 万中文字符**（任务卡 + 规则 + 输入包 + 预留工具返回）。
- 证据包 **≤2.5 万字符**，留 1.5 万给卡/规则/补查/输出。
- 单文件输出 ≤1200 行；超了拆交付件。
- 检索/切块/抽样/行号映射由本地做；不交给 grokbot 做确定性搜索。
- 字符数与模型实际上下文分开记录；4 万是工作上限，不是模型极限。

### 4.5 防"假装读过"（加强版）

- 本地保存实际投递内容 + sha256；验收时随机抽 3 条，要求返回 **证据 ID + 短引文 + 与上下文的关系**；
- 任务卡要求先报读段，但把它当**回执**，不当证明；
- 读不到/答不上 → 本次作废，换输入或换工位。

## 6. 各 WP 规格

### W0 能力预检 + 基线（本地，1 日，先行）

- 本地：读写一个小文件、执行 `verify.py`、算 sha256；

- Openfic：能否导入 1 条世界书条目、读取、回传来源；不能就先不承诺导入。
- 未通过 → 默认"bot 回传 + 本地落盘"，并在任务卡写死。

**W0-2 基线冻结**（`90-日志/基线.json`）：

- 世界书旧稿：sha256 + 行号映射（999 行）；
- 复制旧稿到 `输入包/候选-世界书.md`，文件头写"候选，未经核验，不得直接挂载"。

**W0-3 候选池**：
- `候选-世界书.md`（整份复制，只作覆盖清单）；
- `候选-续写指导摘.md`（只摘总谱/篇幅/禁区，标注"候选"）；
- `候选-禁令候选.md`（从已锁备忘摘 13 条候选，逐条待确认）；
- `候选-锚点候选.md`（旧库外貌/文风样本里抽非 18+ 原句，带行号；只作候选）。

**W0-4 脚本**（`90-日志/脚本/`）：
- `prep_mentions.py`：按交付名+别名抽含名句，**保留前后各 2 句上下文**；维护别名/歧义表；记录命中量、保留量、截断量、章节分布；按主题分包；输出 `证据包/<名>.md`（≤2.5 万字符）+ `统计.json`。
- `split_worldbook.py`：按 15 节 + 附切 5 块，输出候选片段 + 行号映射；不做内容判断。

## 8. 验收合同

### 8.1 三层指标（分开报）

| 指标 | 定义 | 检查 | 门槛 |
|---|---|---|---|
| 字段完整率 | 必填列都有值 | 脚本全量 | 100% |
| 定位有效率 | 证据 ID 能回原文件且行号对 | 脚本全量 + 抽检 | **100%**（不可回的条目必须删除或改到可回） |
| 语义支持率 | 原文确实支持这条结论 | 人工抽检（关键项全量） | **关键项 100%；抽检项 100%**；发现错误必须纠正或整条隔离，**不允许带已知错误通过** |

### 8.2 分类

| 类 | 脚本 | 人工 |
|---|---|---|
| A | 列结构、成句、形容词、≥20 字照抄 | 证据是否支持"值" |
| B | origin≠new 逐字匹配冻结源；origin=new 做 8 字=0；origin 合法 | 可拍摄、人物相关性、new 是否单列 |
| C | 列结构、依据 ID | 是否状态变化、是否动作过程 |
| 18+ | 关键词筛查 | **逐条审读候选片段**；不写"已证明为零" |

### 8.3 不通过

- 编造/来源串错/污染 → 整批隔离，扩大复核，不只修命中项；
- 同一交付件连续 2 次 rework → 换输入或换方法，不无限重开。
